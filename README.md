# Internship Recruitment Analytics Dashboard

## Project Overview
An interactive Power BI dashboard developed to analyze internship recruitment data and understand applicant distribution across different institutions and preferred job roles.

## Dashboard Overview

The dashboard provides insights into:

- Total number of student applicants.
- Total number of participating institutions.
- Gender-wise applicant distribution.
- Preferred internship roles.
- Institution-wise applicant distribution.
- Gender distribution across institutions.

## Key Metrics

- Total Applicants: 1,649
- Total Institutions: 103

## Tools Used
- Microsoft Power BI
- Data Visualization
- Dashboard Design
- Data Analysis

## Project Objective
To visualize internship application trends and provide insights into applicant distribution across colleges, genders, and preferred internship roles.

## Note
This repository contains a dashboard preview. Underlying recruitment data is not shared. Publication of company-related statistics is subject to authorization.
